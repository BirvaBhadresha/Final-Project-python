# Global Happiness Report Analysis

# 📌 Video - https://drive.google.com/file/d/1Xz70fo_pTUu8ARtR3cMzjWoOUZ_gIyDs/view?usp=drive_link

## 📌 Project Overview
This project analyzes the 2024 Global Happiness Report using Python. It explores happiness scores across countries and examines the relationship between happiness and factors such as GDP per capita, social support, and healthy life expectancy.

## 🛠️ Technologies Used
- **Python** – Programming language
- **Pandas** – Data analysis and manipulation
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical visualization

## 📂 Dataset
The project uses `happiness-report-2024.csv`, which contains country-wise happiness scores and related factors.

## ✨ Features
- Displays dataset information and statistical summaries.
- Identifies missing values and handles incomplete records.
- Finds the top 10 happiest and 10 least happy countries.
- Calculates the average happiness score.
- Visualizes happiness scores and their relationships with various factors.
- Generates a correlation heatmap to analyze happiness-related indicators.

## 📊 Visualizations
The project generates charts showing:
- Top 10 Happiest Countries
- Social Support vs. Happiness
- Social Support and Happiness Density
- Healthy Life Expectancy vs. Happiness
- Correlation Between Happiness Factors

## 🎯 Objective
To understand global happiness trends and explore how economic, social, and health-related factors are associated with happiness across countries.

## 🏁 Conclusion
This project demonstrates how Python-based data analysis and visualization can be used to explore the Global Happiness Report and identify patterns in country-level happiness data.
